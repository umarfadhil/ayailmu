One Codex writer, inline execution, as authorized. No push/merge/deployment.

1. Add pure `core:sync` module and standalone JVM test build. Write failing tests
   for consent off, immutable duplicate/conflict, offline restart/recovery,
   cross-owner/learner isolation, expired sessions and stale completion fences.
2. Implement v1 adapter and atomic journal. Match exact native AnswerEvent bytes;
   verify receipt/pull completeness, provenance, consent withdrawal and pagination.
3. Add isolated syncLab flavor and AppAuth shell. Bridge allowlisted synthetic Room
   payloads to the journal; reuse native consent/session routes; display a separate
   native-algorithm projection of provenance-matched synced history.
4. Add separate integration Compose/launch and synthetic login fixtures. Run the
   complete offline/second-client/revoke/expiry/logout flow through the real Kotlin
   client and native engine against Postgres/Keycloak. Build/test Android, record
   evidence, review fixes and remaining release blockers; commit locally.
