# Unit A evidence pilot design

Coordination design from the user's October25 forward-building instruction and the completed Opus pedagogy audit. Reversible defaults below are implementation hypotheses, not validated learning standards. Claude Code Opus5.5 max is the product/content/test author; Codex coordinates and verifies.

## Goal and boundaries
Build one reachable developer UnitA loop for Indonesian-speaking adults: short worked example, four-choice practice, misconception feedback, unfamiliar-combination assessment and delayed D7/D30 observations. Keep the existing stack. No blanks/required typing, new curriculum beyond UnitA, XP implementation, credentials/services, merge or deployment.

All newly authored material remains constructed practice, synthetic/draft and explicitly unreviewed. Tester mode and direct navigation must not expose it. Qualified Arabic and Indonesian review plus real learner evidence remain separate release gates. Nothing is Quran text or evidence of Quran comprehension.

## Chosen incremental approach
Keep the frozen v0.3 pack, existing sessions, answer records and semantics. Add a versioned UnitA developer pilot entry/route and focused modules. This preserves historical meaning and permits comparison while new policy remains provisional. Replacing the default curriculum or retroactively grading old answers would create a broader migration and is deferred.

Use the AppContext-selected Store for separate pilot metadata; never overwrite the legacy learning snapshot or mix guest/account stores. Until explicitly implemented, pilot progress is local to its selected dataset and is not claimed to sync or be included in server account exports. Surface this limitation. Unknown/newer content, policy or storage versions fail closed without erasing history.

## Provisional evidence hypothesis
The pure eligibility core consumes already owner/version/catalogue-validated events in canonical append-log order. Each reference/agreement construct requires correct first attempts on at least two distinct practice families, then a correct first unfamiliar-family transfer on a later real local calendar day. Event IDs count once; retries do not turn a wrong first attempt into fresh evidence. Freshness is exposure before the assessment; later practice does not rewrite an earlier valid observation.

Call the result provisional eligibility, never learned/mastered/remembered. The threshold is deliberately reversible and unvalidated; do not infer efficacy or percentages from passing tests. D7/D30 results stay separate descriptive observations, with stable anchors and exposure guards. If fresh content is exhausted, retain an honest insufficient-evidence state and useful practice rather than fabricate success.

## Content and learner flow
Interleave brief teaching and practice, preserve four defensible options/one key, stable saved presentation order and concise Indonesian feedback. Reserve unfamiliar combinations and delayed task families from earlier lesson/Guide/practice/distractor/feedback exposure. Previously taught vocabulary is expected and does not itself invalidate retention. Do not disclose later answers within an unfinished assessment block.

Save progress before showing success; cover duplicate taps, interrupted writes, reloads, readonly stores and account switches. Existing auth/profile/consent/export/deletion behavior remains protected. The final learner-facing pilot must be reachable, not merely a dormant library.

## Human review and next decisions
Review every Arabic stem, vowels, gloss, key and distractor, Indonesian wording, construct/family independence and reserved-set boundaries. Record pending sign-off honestly. After approval, an adult feasibility pilot should inspect first-attempt, unfamiliar-combination and delayed outcomes; that still would not prove comparative efficacy.

XP stays secondary and absent. A later explicit decision may use transparent workload/effort points, with no role in evidence-based unlocks and no mastery claim. No leaderboards, currencies or streak penalties are introduced here.
